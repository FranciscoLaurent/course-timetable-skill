# 页面能力与导出行为（交付时讲给用户听）

这份文件是**给用户看的说明书**，不是 agent 的执行规则 —— 所以它不在 SKILL.md 里占篇幅。
交付时挑用户用得上的讲，不用照读。

---

## 1. 两种看法，一键切换（默认「按周查看」）

| 模式 | 看什么 | 怎么切 |
|---|---|---|
| **按周查看**（默认） | 下拉框选「第 N 周」，页面只显示那一周；下拉里每项后面标了该周门次 | 左上角「按周查看」按钮 |
| **学期总览** | 把**整个学期所有课程**汇总进一张表。同一格里有多门课时**上下叠放全都写上**，每门课带自己的周次 —— 例如 A 课 8-16 周周一 3-4、B 课 17-20 周周一 3-4，那一格里 A、B 都出现。行高由内容自动撑开，不会挤在一起 | 左上角「学期总览」按钮 |

- 周次也可以直接改地址栏：`?week=9`
- 切换状态记在地址栏（`?scope=overview`）与浏览器本地，下次打开还是上次的样子

## 2. 电脑版 / 手机版

- 页面右上有「电脑版 / 手机版」按钮；**默认按屏幕宽度自动选**，手动切过后会记住（`?view=`）
- **手机版**把课表装进一个手机外观里（机身 390×844、灵动岛、状态栏、App 内导航栏），
  内容是**按天纵向卡片**，窄屏不用左右拖；手机里的选周控件与页面双向同步
- 舞台背景是**蓝白学术风**（浅蓝渐变 + 极淡坐标格 + 超大「课」「表」两字），与表格页同一套配色
- **真的用手机打开时（≤560px）自动去掉机身和舞台、铺满屏幕**，免得"手机里套手机"
- 窄屏停在电脑版时，表格可以左右滚动，不会撑破布局

## 3. 导出 PDF

点「导出 PDF」调起打印对话框，**把「目标打印机」选成「另存为 PDF」**即可
（页面上会弹提示引导这一步 —— 浏览器不允许网页直接生成 PDF，只能走打印）。

**纸张尺寸跟着当前状态走**：

| 当前状态 | 纸张 | 分页 |
|---|---|---|
| 电脑版 | A4 横向 | 内容多时自动分页 |
| 手机版 + 按周 | 与「导出图片」手机版画布**完全同尺寸**的竖版页面（手机宽 × 内容高） | **保证一页** |
| 手机版 + 总览 | 手机宽度 × A4 高度（111 × 297mm） | **允许超过一页**，卡片不会被拦腰截断 |

## 4. 导出图片

点「导出图片」直接下载 PNG，**当前是什么状态就导什么** —— 按周 / 总览 × 电脑版 / 手机版
四种组合各自对应一张图。

- 实现是**纯 SVG → Canvas**，不依赖任何外部库，离线可用
- 导出分辨率 2 倍，发群里看得清
- 文件名形如 `第8周课表.png` / `学期课表总览_手机版.png`
  （标题带了姓名时是 `张三第8周课表.png`）

## 5. 其它

- 下拉框选周次，「上一周 / 下一周」按钮，或键盘 `←` `→`
- 地址栏会记住周次与视图（`?week=9&view=mobile`）
- **单文件、不联网**，可以直接发给别人（微信、邮件都行），对方双击就能看

## 6. 手机上怎么用最省事

把 HTML 发到手机 → 用浏览器打开 → 就是手机版效果。
要给别人看某一天的课，切到那一周点「导出图片」，发 PNG 即可。
